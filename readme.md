# Multi-Lives-Youtube

Player web para exibição simultânea de múltiplas lives do YouTube.

## ✨ Visão geral

Ferramenta criada para assistir várias transmissões ao vivo ao mesmo tempo, organizada em grade responsiva.

## 🚀 Tecnologias

- HTML
- CSS
- JavaScript

## 📦 Funcionalidades

- Suporte a múltiplas lives simultâneas
- Layout em grid
- Interface leve e rápida
- Integração com embeds do YouTube

## ⚙️ Como rodar o projeto

Basta abrir o arquivo `index.html` em um navegador.
